# Hosted EXE 风格首批实现

## 变化

- `src/ui/theme.css` 保存 EXE 原有深浅色主题变量，两端共同导入。EXE 的原变量值保持不变。
- Hosted 现有登录、验证码、账号、配置、邀请、迁移、管理列表和弹窗使用共享表面、文字、强调色和状态色。二维码保留白底。
- 新账号工作台采用品牌顶栏、侧栏、统计卡片、直播间和账号卡片。窄屏改为横向导航和单列内容。
- 统计读取真实 `loadConfiguration()`；失败显示不可用并允许重试，不显示伪造的零值。OBS 数量明确表示组合画面定义数。
- 页面离开后停止本地更新和房间订阅；已发出的退出请求成功返回时仍清理当前应用视图，避免切页后遗留已退出账号内容。
- Dockerfile 与精简构建上下文均包含共享主题、品牌模块及 SVG。
