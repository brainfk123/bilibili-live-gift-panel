# Hosted UI 风格约束

维护者于 2026-09-06 明确要求：**Hosted 新增的功能也延续 EXE 的 UI 风格。**
本约束覆盖已迁移工作区、后续新增功能，以及账号、邀请、迁移、权限和管理页面。功能语义可以因在线服务而扩展，视觉和交互应属于同一套设计体系。

## 设计来源

以固定 EXE v0.4.10 的实际截图为参考；共享主题变量已提取到 `src/ui/theme.css`，由 EXE 配置 CSS 与 Hosted CSS 共同导入。布局和交互来源为 `src/ui/config/config.css`、`config-shell.ts`、`config-route.ts`、`src/ui/common.ts` 以及相应编辑器组件。

| 项目 | EXE 来源 / 约束 |
| --- | --- |
| 深色底色 / 次级底色 | `--bg: #14151a` / `--bg-soft: #1c1e26` |
| 卡片 / 边框 | `--card: #22242e` / `--border: #2e3140` |
| 主文字 / 辅助文字 | `--text: #e6e8ee` / `--text-dim: #9aa0b0` |
| 强调色 | `--accent: #fb7299`；主操作、选中态和高亮遵循 EXE 对应用法 |
| 字体 | Segoe UI、PingFang SC、Microsoft YaHei、system-ui 回退顺序 |
| 字号层级 | 页面 28–32px，分区 20px，标题 16px，正文 14px，说明 12px |
| 基础圆角 | `--radius: 12px`；具体卡片与弹窗使用对应组件规格 |
| 浅色模式 | 使用 EXE `[data-theme="light"]` 的成组变量，包含文字对比、主按钮和焦点色 |
| 响应式 | 延续桌面侧栏、窄屏重排、移动端横向导航和单列内容的规则；沿用三个合同视口 |

本表是来源索引，不是对所有组件尺寸的硬编码替代。间距、边框、悬停、聚焦、按钮尺寸和弹窗宽度应由对应基础组件继承。

## 新增功能的组件映射

| Hosted 功能 | 应采用的 EXE 视觉模式 |
| --- | --- |
| 登录与账号验证 | 现有账号卡片、字段标签、状态提示、主/次操作和验证弹窗 |
| 邀请码、配额、会话列表 | 数据中心的分组列表、辅助信息层级、状态标签、筛选和确认操作 |
| 配置迁移预览与应用 | 属性工作台的分区导航、概览卡片、字段对照、底部保存/取消操作 |
| 只读、账号禁用、权限不足 | 现有状态标签与禁用控件风格，加上明确原因和可执行的下一步 |
| 管理后台 | 相同主题、卡片、列表、表单和弹窗组件；管理功能按任务组织，不另设一套视觉主题 |
| 新的玩法或统计能力 | 选择最接近的现有工作区模式，再扩展对应内容和状态 |

安全操作保留 Hosted 的身份验证、CSRF、修订冲突和确认流程。错误信息应在当前操作区域或弹窗内可见；EXE 中发现的 toast 遮挡或布局抖动不作为需要复制的风格特征。

## 验收方式

1. 已存在于 EXE 的功能：继续按 EXE/Hosted 状态与视口合同直接对比截图。
2. Hosted 独有功能：记录最接近的 EXE 参考组件、采用的变量和交互模式，采集新功能各相关状态，检查风格一致性。
3. 两类页面都检查字体与信息层级、卡片/表单/按钮/弹窗、间距、focus-visible、加载/错误/空态、只读/禁用以及窄屏布局。
4. Hosted 独有功能没有对应 EXE 截图时，记录为“风格继承验收”，不伪造一对一对等证据；它仍受本约束约束。
5. 截图可在同一 macOS 浏览器中采集，按维护者要求暂不比较浏览器平台差异。

首批实现已将现有 Hosted 登录、账号、配置、邀请、迁移及管理样式切换到共享主题，并重做账号工作台。账号页可切换深浅色，读取真实配置统计并进入已有功能。六工作区的完整可视化编辑器、迁移 v2 兼容和全部状态对齐仍须按各自验收推进。
