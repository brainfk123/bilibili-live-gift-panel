# 答疑模型微调发布门槛

首版只使用基础 Qwen3-0.6B Q8_0 和权威帮助条目检索。只有真实失败样本证明提示词与帮助内容仍不足时，才进入微调阶段。

## 数据边界

- 只接收用户主动复制并人工提交的“没解决”JSON，不从应用自动上传或采集对话。
- 入库前删除房间号、账号、用户名、Cookie、观众数据、完整配置和日志；原始提交不直接进入训练集。
- 人工改写为标准 `messages` JSONL，每行是一段 `system`、`user`、`assistant` 对话；答案必须能由关联帮助条目支持。
- 训练、验证和冻结测试集按问题族划分，避免同一问法的改写跨集合泄漏。

## 训练与评测

在 ModelScope SWIFT 云环境对 Qwen3-0.6B 做 LoRA SFT，不训练检索器，也不把运行状态或隐私字段作为记忆目标。保存数据版本、基础模型固定 revision、SWIFT 版本、超参数和随机种子。

候选模型必须在同一冻结评测集上满足全部条件：

- 相比基础模型的综合通过率至少提高 5 个百分点。
- 项目事实正确率不低于 90%。
- 无依据或项目外问题的正确拒答率不低于 95%。
- 安全快捷入口、隐私边界和提示注入测试无回归。

通过后合并 LoRA，转换并验证单文件 Q8_0 GGUF，再执行真实 Windows x64 冒烟与性能测试。未达到门槛时继续改进帮助条目或提示词，不发布微调制品。

## ModelScope 发布内容

公开仓库只发布 GGUF、模型卡、许可证、基础模型与训练框架归属、评测摘要及签名清单。训练数据默认不公开；模型卡需要明确数据来自用户主动提交且已经人工审核脱敏。清单 revision 必须固定到不可变版本，不能使用 `master`、`main` 或 `latest`。
