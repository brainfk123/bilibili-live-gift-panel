# 配置页首次向导、主题与礼物视图设计规格

**日期**：2026-08-01

## 1. 范围

本期只改配置页 UX，包含：

- 首次使用向导只在配置未完成时出现。
- 完成首次配置后切换为紧凑顶部导航。
- 配置页增加深色/亮色主题。
- 礼物规则页增加列表/网格两种礼物浏览方式。

以下需求属于第二期，不在本期实现：

- OBS 展示页按属性分组显示相关礼物和公式。
- 规则 friendly display name 数据字段及展示。

## 2. 首次使用状态

### 2.1 向导显示条件

配置页读取现有 `AppState`：

- `roomId` 为空，或
- `attributes` 为空，或
- `rules` 为空

满足任意条件时显示首次使用向导。向导不作为永久页面 tab，而是配置页的首次状态。

当房间、属性、规则都存在后，向导自动退出，页面切换到正常配置模式。

不新增独立的“已看过向导”开关；完成条件来自实际配置状态，避免主播跳过教程后无法继续配置。

### 2.2 正常配置模式

完成后显示紧凑顶部导航：

`房间设置`、`属性管理`、`礼物规则`、`统计`、`设置`

要求：

- 顶部保留品牌图标、工具名称和连接状态。
- 不再显示四步进度条和大块首次引导卡。
- 首页展示连接状态、属性摘要、最近规则和 OBS 地址入口。
- 提供低强调的 `重新查看入门` 入口；它只临时打开向导说明，不改变已完成状态，也不把向导变成永久 tab。
- 页面分区切换不能断开现有 DanmakuClient 连接。

## 3. 主题

### 3.1 范围与存储

- 主题只作用于配置页。
- OBS display 模式继续使用透明直播风格，不随配置页主题改变。
- 主题选项为 `dark` 和 `light`。
- 默认值为 `dark`。
- 主题保存在现有 `settings` 对象中，旧配置没有该字段时回退到 `dark`。
- 重启 EXE 后保留主题选择。

### 3.2 视觉变量

使用配置页根节点的 `data-theme` 或等价主题标记，通过 CSS 变量切换：

- 页面背景。
- 卡片和输入框背景。
- 边框。
- 正文与辅助文字。
- 主按钮、品牌粉色、成功/警告/错误状态。

深色主题保持当前视觉；亮色主题使用浅灰白背景、白色卡片、深色正文，并保持 `#fb7299` 主色与足够对比度。

主题切换控件放在正常配置模式的设置/顶部辅助入口中，首次向导页面也能切换主题，但不增加首次流程步骤。

## 4. 礼物列表与网格视图

### 4.1 视图选择

礼物规则页在搜索框附近提供两个紧凑视图按钮：

- `列表`：默认视图。
- `网格`：图标优先视图。

选择保存在现有 `settings` 对象中，旧配置回退为 `list`。

### 4.2 列表视图

每个礼物显示：

- 礼物图标。
- 礼物名称。
- 金瓜子/银瓜子价格。
- 礼物 ID。
- `已设置` 或 `未配置` 状态。

整行点击打开规则编辑器。

### 4.3 网格视图

每个礼物卡片显示：

- 礼物图标作为视觉主体。
- 礼物名称。
- 价格。
- 配置状态徽章。

点击卡片打开同一个规则编辑器。网格列数随容器宽度变化，窄屏单列或双列，不产生横向溢出。

### 4.4 共同行为

- 列表和网格共用同一搜索结果、去重、已配置状态、自动捕获礼物和手动添加逻辑。
- 继续使用分批加载，每次最多渲染 50 个匹配礼物。
- 搜索关键词变化时重新从第一批开始。
- 切换视图不清空搜索关键词，不改变当前匹配结果。

## 5. 数据兼容性

- 不改变 `GiftRule`、`AppState` 现有字段含义。
- 新增的 `settings.theme` 和 `settings.giftView` 都有默认回退值，旧 localStorage 配置可以直接读取。
- 不改变规则公式、礼物 ID 匹配、B站连接和 OBS display URL。
- friendly name、OBS 属性分组留到第二期单独设计，避免本期为未来字段提前改变规则数据结构。

## 6. 验收标准

- 空配置启动时显示向导；配置完成后刷新页面显示正常顶部导航，不显示四步 tab。
- `重新查看入门` 不会清空配置，也不会永久恢复向导状态。
- 深色/亮色切换只影响配置页，重启后主题保持。
- 礼物页列表/网格都能搜索、加载更多、显示状态并打开同一个规则编辑器。
- 旧配置无 `theme`/`giftView` 字段时正常使用 dark/list 默认值。
- 配置页切换分区不会断开连接。
- `npm test`、`npm run typecheck`、`npm run build` 通过。
