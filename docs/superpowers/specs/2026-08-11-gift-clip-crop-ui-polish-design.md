# 礼物动画剪裁框 UI/UX 优化设计

## 背景与目标

现有礼物动画剪裁编辑器已经具备原始像素剪裁、8 向缩放、键盘调整、预设保存和成片录制能力。本轮不改变剪裁工作流，而是提升剪裁框的可发现性、操作容错和专业编辑器质感，并补充成片尺寸上限。

目标：

- 裁剪模式使用明确的直角视觉，不再让圆角边界暗示最终成片会保留圆角。
- 用克制的 L 形角标、边中点标记和标准光标表达移动与缩放能力。
- 扩大实际拖拽热区，但不增加视觉噪声。
- 只在用户实际调整时显示构图辅助线。
- 将成片剪裁区域的任一边限制在 4096px 以内。
- 保持配置页与礼物动画工作室之间的外部 seam 稳定，避免把逻辑重新堆回 `gift-clip-studio.ts`。

## 参考与方案选择

设计参考以下成熟工具的通用交互语言：

- [Figma 图片剪裁](https://help.figma.com/hc/en-us/articles/360040675194-Crop-an-image)：操作区域、拖动重定位和方向缩放光标之间有清楚区分。
- [Cropper.js](https://fengyuanchen.github.io/cropperjs/)：使用方向明确的边与角控制区域表达 8 向缩放。
- [Pintura Image Editor](https://pqina.nl/pintura/tour/)：通过遮罩、构图辅助和响应式输入支持聚焦有效画面。

比较过的视觉方向：

1. 专业编辑器：双层边线、矩形控制点、三分线。
2. 极简角标：直角边界、L 形角标、低干扰边标和较大的隐藏热区。
3. 高对比经典：黑白边线、方形节点和持续可见辅助线。

采用方案 2。它保留 8 向操作的完整能力，同时最符合现有配置页的轻量视觉。用户已确认框内采用抓取手势，并仅在实际调整期间显示三分辅助线。

## 范围

本轮包含：

- 裁剪预览面板、裁剪视口、遮罩和裁剪框的直角化。
- L 形角标、边中点标记、热区、悬停/活动/焦点样式。
- 框内抓取光标、8 向缩放光标和活动状态管理。
- 拖动、缩放与键盘调整期间的三分辅助线。
- 4096px 成片剪裁区域上限。
- 单元、DOM 交互、Playwright 和视觉验收。

本轮不包含：

- 不改变外层编辑弹窗的现有圆角和响应式形态。
- 不改变信息条自身的圆角设计。
- 不改变媒体解码、录制格式、保存文件、剪裁预设持久化或关闭弹窗的语义。
- 不新增固定宽高比、旋转、缩放素材、自由透视或自定义裁剪比例。
- 不使用自定义位图光标。

## 视觉设计

### 直角范围

弹窗内的动画预览面板始终使用直角，包括素材预览、生成后的视频预览、裁剪视口、外部遮罩边界和裁剪框。以上区域的计算样式均应为 `border-radius: 0`。

外层编辑弹窗继续沿用当前视觉：桌面端保留圆角；窄屏全屏形态继续沿用现有响应式规则。本轮不改变弹窗 shell。

### 裁剪框

- 主边界是一条 1px 半透明浅色细线，保持方形边角。
- 四角显示约 20×20px、2px 线宽的强调色 L 形角标。
- 四边中点显示短条形标记，不显示圆点。
- 角标和边标由伪元素或不参与布局的绘制层实现，不用会改变框体尺寸的边框增量。
- 框外使用中性深黑半透明遮罩；框内不叠加强色滤镜。
- 活动强调色沿用配置页主题 accent，并保证在深色背景上的辨识度。

### 可见标记与实际热区分离

视觉角标和边标保持轻量；对应的按钮热区向外扩展：

- 常规桌面视口约 28×28px。
- 窄屏约 32×32px。
- 热区背景透明，只有标记本身可见。
- 相邻热区不得覆盖框体中心的移动区域，也不得改变几何计算所使用的框体边界。

### 视觉状态

- 空闲：角标清晰，主边界和边中点标记保持低干扰。
- 悬停：仅提亮当前方向对应的角标或边标。
- 调整：裁剪框强调色略增强，三分辅助线淡入。
- 键盘焦点：当前框体或控制点显示清晰的 `focus-visible` 外环。
- 禁用或销毁：不得保留悬停以外的活动类、辅助线或抓取状态。

## 光标与交互

### 指针光标

- 框体中心：空闲时使用原生 `grab`，按下并捕获指针后使用 `grabbing`。
- 上/下边：`ns-resize`。
- 左/右边：`ew-resize`。
- 左上/右下角：`nwse-resize`。
- 右上/左下角：`nesw-resize`。

使用操作系统原生光标，避免自定义位图在高 DPI、多平台缩放和辅助设置下模糊或不一致。

### 指针状态

1. 主按钮在框体或控制热区按下后，记录指针 ID、起点、初始剪裁区域、显示尺寸和操作方向。
2. 框体捕获该指针并进入活动状态；中心移动同时切换为 `grabbing`。
3. 拖动继续复用纯几何模块计算像素变化和边界约束。
4. `pointerup`、`pointercancel` 或 `lostpointercapture` 都必须结束活动状态、隐藏辅助线并恢复光标。
5. 右键、重复指针或编辑器销毁后的事件不启动操作。

### 三分辅助线

- 空闲和普通悬停时不显示。
- 指针移动或缩放开始后淡入，操作结束后淡出。
- 方向键调整期间显示，`keyup` 或失焦后隐藏。
- 辅助线使用两条水平线和两条垂直线，不接受指针事件，不进入无障碍树。
- 动画只改变透明度，不改变裁剪框尺寸或布局。

### 键盘与无障碍

- 框体和 8 个控制点继续可聚焦。
- 方向键调整 1 个源像素，`Shift + 方向键` 调整 10 个源像素。
- 边控制点只响应与其轴向匹配的方向键；角控制点响应两个轴向。
- 保留中文 `aria-label`，并使标签准确描述移动或对应边角调整。
- `prefers-reduced-motion: reduce` 下取消辅助线和强调色过渡。

## 4096px 上限

`4096px` 是成片剪裁区域任一原始像素边长的上限，不是预览 DOM 的 CSS 尺寸，也不是拒绝读取大素材的门槛。

- 剪裁宽度和高度各自限制在 `64..4096px`，同时不能超过素材对应边长。
- 宽高均不超过 4096px 的素材默认选择完整画面。
- 素材任一边超过 4096px 时，初次完整画面默认值会转换为居中的有界选区：

```text
cropWidth  = min(sourceWidth, 4096)
cropHeight = min(sourceHeight, 4096)
cropX      = floor((sourceWidth  - cropWidth)  / 2)
cropY      = floor((sourceHeight - cropHeight) / 2)
```

- “恢复完整画面”在大素材上恢复为上述居中最大选区，而不是创建超限成片。
- 移动保持当前宽高，只限制位置。
- 从东/南侧向外缩放时，活动边不能超过固定边加 4096px；从西/北侧向外缩放时，活动边不能超过固定边减 4096px。
- 归一化持久化格式不变；读取后结合实际素材尺寸再次应用 64px 下限、4096px 上限和素材边界。
- 输出 Canvas 和录制视频继续精确使用最终剪裁像素尺寸，因此每个输出维度也不会超过 4096px。

现有完整礼物特效合成尺寸校验和 GIF 解码安全限制继续保留；本约束不放宽任何媒体安全门槛。

## 模块边界与稳定 seam

配置页继续只依赖 `giftClipAnimationKey()` 和 `openGiftClipStudio()`。`GiftClipStudioOptions`、`GiftClipStudioController`、剪裁确认回调、关闭行为和保存时机保持不变。

### `gift-clip-crop.ts`

- 在模块内部统一拥有 4096px 剪裁边长常量，不为视觉层或测试扩大公开接口。
- 在像素区域约束、8 向缩放、默认/重置选区和持久化数据重约束中执行上限。
- 继续保持无 DOM、无 Canvas、无网络 I/O 的纯计算模块。

### `gift-clip-crop-editor.ts`

- 继续拥有裁剪 DOM、Pointer Events、键盘状态、活动类和销毁清理。
- 允许增加装饰性辅助线节点或伪元素所需的状态类。
- 保持现有 `GiftClipCropEditor` 的 `element`、`getCrop()`、`reset()`、`destroy()` 接口不变。
- 不复制几何约束，不负责持久化或录制。
- 交互测试通过 `createGiftClipCropEditor()` 返回的既有接口和 `element` 中的可观察结果验证行为，不导出内部 drag state 或视觉配置。

### `gift-clip-studio.ts`

- 不承接新视觉或指针状态逻辑。
- 原则上本轮不修改；只有在测试证明无法从现有裁剪编辑器 seam 完成要求时，才允许做最小接线调整，并必须保持其公开接口完全不变。

### `config.css`

- 负责直角预览、遮罩、角标、边标、热区、光标、焦点和响应式样式。
- 使用现有 `.config-root` 作用域，避免污染其他页面。
- 通过伪元素、outline 或非布局阴影绘制强调层，防止边框引起 480px 舞台/图层尺寸偏差。

## 生命周期与异常清理

- `reset()` 重建符合素材尺寸和 4096px 上限的默认选区，并清除活动状态。
- `destroy()` 释放已有指针捕获，清空 drag state，移除 pointer/keyboard/focus 处理器和 DOM 图层。
- 指针取消或捕获丢失与正常松手走同一活动状态收口逻辑。
- 重新剪裁、开始录制、关闭弹窗或媒体错误不能留下三分线、`grabbing` 光标或全局事件监听器。
- 视觉状态切换本身不得额外触发 `onChange`；现有首次渲染和剪裁几何更新的通知流程保持不变。

## TDD 与提交边界

实现计划应拆成可独立验证和提交的任务，每个任务遵循红—绿—重构：

1. 4096px 纯几何与默认/重置行为。
2. 裁剪编辑器活动状态、辅助线、键盘和清理行为。
3. 直角面板、方案 B 标记、热区、光标和响应式 CSS。
4. Playwright 交互、计算样式、截图和完整回归验收。

每个任务先写能因缺失行为而失败的测试，再写最小实现，通过相关测试后独立提交。不得把多个未经验证的任务压成一个提交。

## 验收标准

### 单元与 DOM 测试

- 4096px 边界值、4097px 超限值和大素材居中默认选区。
- 8 个方向分别遵守 64px 下限、4096px 上限和素材边界。
- 移动不改变宽高，重置在大素材上回到居中最大选区。
- 指针按下/松开/取消/丢失捕获正确切换活动状态。
- 框内与 8 个控制点使用正确操作方向。
- 方向键、Shift 步长、`keyup`/失焦和销毁清理正确。
- `GiftClipCropEditor` 与礼物动画工作室公开 seam 不变。

### Playwright 与视觉验收

- 动画预览面板、媒体层、裁剪视口和裁剪框的计算 `border-radius` 为 `0px`；弹窗 shell 仍保持现有样式。
- 8 个控制热区全部存在，桌面/窄屏命中尺寸达到设计值。
- 中心、四边和四角的计算 cursor 分别匹配 `grab` 与方向缩放光标；拖动时为 `grabbing`。
- 三分线空闲隐藏，指针或键盘调整时显示，操作结束后隐藏。
- 裁剪框始终位于舞台内，成片宽高不超过 4096px。
- 桌面和移动端无水平溢出、无控制台错误；更新截图并人工检查角标、边标、遮罩和弹窗圆角范围。

### 完整回归

- TypeScript 类型检查。
- 全量 Vitest。
- Vite 生产构建。
- Go 测试与 vet。
- Playwright 专项验收。
- Windows EXE 构建。

完成后仍按既定交付约束合并到本地 `master` 并构建 EXE；保留主仓库所有未跟踪文件，不推送、不发布。
