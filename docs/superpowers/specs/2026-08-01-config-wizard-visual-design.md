# 配置向导与品牌图标视觉设计规格

**日期**：2026-08-01

## 1. 目标

配置页面向不熟悉技术的主播。用户双击 `gift-panel.exe` 后，应能只依靠页面上的短提示和按钮完成首次配置，不需要先阅读 README。

本次改动解决三个问题：

- 当前侧栏和多个说明卡同时出现，视觉重点不明确。
- 说明文字重复且过长，干扰用户完成当前任务。
- 页面和 Windows EXE 没有统一的品牌识别。

## 2. 信息架构

### 2.1 首次使用向导

首次使用时，配置页采用单一主流程：

`连接房间` → `设置属性` → `绑定礼物` → `放进 OBS`

页面结构：

- 顶部品牌栏：品牌图标、工具名称、连接状态。
- 顶部四步进度条：当前步骤高亮，已完成步骤显示勾号，未完成步骤弱化。
- 主内容区：只突出当前步骤的一个主卡片。
- 主按钮：每个步骤只保留一个主要动作，如“测试连接”“下一步”。
- 辅助说明：默认只显示一句；详细内容放入可展开的 `details/summary` 区域。

首次使用时不显示复杂的侧栏表单。统计、设置、手动添加礼物等功能仍保留，但作为“更多设置/高级设置”进入，避免小白首次打开就看到大量选项。

### 2.2 四个步骤

#### 步骤一：连接房间

- 标题：`输入你的直播间房间号`
- 常驻说明：`填好后点击测试连接。`
- 输入标签：`房间号`
- 主按钮：`测试连接`
- 可展开提示标题：`房间号在哪里？`
- 展开内容必须准确说明：房间号是 URL 中 `live.bilibili.com/` 后、查询参数 `?` 前的路径数字，不是整条 URL 最后出现的数字。
- 示例：
  `https://live.bilibili.com/88888888?live_from=1111&visit_id=...`
  应填写 `88888888`。

#### 步骤二：设置属性

- 默认展示“加班时间”属性，主播可以直接使用。
- 只突出名称、初始值、显示格式三个常用字段。
- 封顶、限次等规则不在这一步展开。
- 页面说明保持一句：`属性就是礼物触发后会变化的数字，例如加班时间。`

#### 步骤三：绑定礼物

- 按 `搜索礼物` → `选择属性` → `选择公式示例` → `保存规则` 的顺序排列。
- 公式教程默认折叠，标题为 `不会写公式？看示例`。
- 封顶、每日限次、最低门槛放入 `可选限制` 折叠区域。
- 没有规则时，空状态只保留一条行动提示：`先搜索一个观众会送的礼物。`

#### 步骤四：放进 OBS

- 显示可复制的 OBS 地址：`http://localhost:12450/?mode=display`。
- 提供 `复制地址` 主按钮。
- 操作说明最多三行：
  1. OBS 添加“浏览器”来源。
  2. 粘贴地址并设置宽高。
  3. 保持 `gift-panel.exe` 运行。

### 2.3 完成后的状态

完成四步后，页面不再显示大段引导，改为简洁状态首页：

- 当前连接状态。
- 属性预览卡片。
- 最近一条规则。
- 一个低强调的 `重新查看向导` 入口。

## 3. 视觉语言

### 3.1 布局

- 深色背景保留，减少大面积无内容的黑色区域。
- 主内容最大宽度约 960px，桌面端居中。
- 主卡片使用圆角、细边框和轻微渐变，不使用过重的玻璃模糊。
- 进度条使用数字圆点 + 细连接线，不使用多个同等权重的胶囊按钮。
- 移动端改为单列卡片，进度条两列换行，输入和按钮纵向排列。

### 3.2 颜色

- 页面背景：`#12131a` 到 `#1b1d28`。
- 主色：B站粉 `#fb7299`，用于当前步骤和主要按钮。
- 高光：橙色 `#ffad66`，用于礼物/时间相关图标和提示。
- 成功色：绿色 `#4ade80`，用于连接成功和已完成步骤。
- 正文使用高对比浅色，辅助说明使用低对比灰色。

### 3.3 文字

- 页面标题短而明确，避免同一件事同时出现在标题、卡片和底部说明中。
- 每个主卡片最多一条常驻说明。
- 详细解释默认折叠，使用“在哪里”“为什么”“不会写怎么办”等动作型标题。
- 代码/URL 使用等宽字体并允许横向滚动，不截断关键数字。

## 4. 品牌图标

### 4.1 图形

统一使用“礼物盒 + 小时钟”组合：

- 礼物盒表达礼物触发。
- 小时钟表达加班时间等属性。
- 礼物盒使用粉色，时钟或高光使用橙色。
- 使用 SVG 作为页面 logo 和 favicon，保证缩放清晰。
- 页面顶部、空状态、OBS 完成预览使用同一图形，不再混用 emoji 作为主要品牌标识。

### 4.2 EXE 图标

- 从同一 SVG 生成 Windows `.ico`，至少包含 16、32、48、256 像素尺寸。
- Go 构建通过 Windows 资源文件嵌入图标，使资源管理器、任务栏和快捷方式显示统一图标。
- 图标资源不影响 exe 的单文件分发和内嵌页面。

## 5. 兼容性约束

- 不改变现有 `?mode=config` 和 `?mode=display` URL。
- 不改变 localStorage 数据结构、公式语法、礼物规则行为和 Go 代理 API。
- 保留现有配置功能；只是把低频选项收进折叠区域或高级入口。
- 页面继续由 Go exe 内嵌的单 HTML 提供，不增加主播端运行时依赖。
- 所有新增图标默认使用 ASCII/英文标识符，用户可见中文文案按本规格书写。

## 6. 验收标准

- 双击 exe 自动打开配置页，第一屏能明确告诉用户当前唯一下一步。
- 首次屏幕不出现重复的房间号说明。
- 房间号提示明确区分 URL 路径数字与 `?` 后查询参数。
- 详细说明默认收起，展开后仍能完整解释操作。
- 完成配置后可一键复制 OBS 地址。
- 页面在桌面和窄屏下都不出现横向溢出。
- 页面 logo、favicon 和 EXE 文件图标使用同一视觉符号。
- `npm test`、`npm run typecheck`、`npm run build` 和 `go test ./...` 通过。
